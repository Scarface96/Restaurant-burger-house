# Restaurant Burger House

A modern restaurant website for a burger house featuring menu showcase, ordering system, and restaurant information.

## 📋 Overview

A professional restaurant website built with HTML and CSS showcasing a burger house menu, promoting dining experience, and providing contact information.

## 🍔 Features

- **Responsive Design** – Mobile and desktop optimized
- **Menu Display** – Showcase burger options with descriptions
- **Image Gallery** – Food and restaurant photos
- **Ordering System** – Simple order placement
- **Contact Information** – Location, phone, hours
- **Navigation** – Easy-to-use menu structure
- **Reviews Section** – Customer testimonials
- **Social Media Links** – Connect on social platforms

## 🛠️ Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Styling and animations
- **JavaScript** – Interactive elements (optional)
- **No Framework** – Pure vanilla code

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Scarface96/Restaurant-burger-house.git
cd Restaurant-burger-house

# Open in browser
open index.html  # macOS
# or
start index.html  # Windows
```

Or run a local server:
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

Then visit `http://localhost:8000`

## 📱 Sections

- **Header** – Logo and navigation
- **Hero Banner** – Eye-catching welcome section
- **Menu** – Burger options with prices
- **Special Offers** – Promotions and combos
- **Gallery** – Food and ambiance photos
- **Reviews** – Customer testimonials
- **Contact** – Location, phone, email
- **Footer** – Links and social media

## 📖 How to Use

1. **Browse Menu** – View burger options
2. **Check Specials** – See current promotions
3. **Order Online** – Place food orders
4. **Contact** – Call or visit location
5. **Follow** – Connect on social media

## 🎨 Customization

Edit `index.html` and `style.css` to:
- Update menu items
- Change restaurant information
- Modify colors and branding
- Add new sections
